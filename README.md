# WHEN - Okulların Açılmasına / Kapanmasına Ne Kadar Kaldı? 🎒⏰

Modern, profesyonel ve mobil uyumlu MEB Eğitim-Öğretim Takvimi canlı geri sayım ve interaktif okul takvimi uygulaması.

## 🚀 Canlı Özellikler
- 🗓️ **Canlı Geri Sayım:** Gün, Saat, Dakika ve Saniye bazında `target - now` timestamp senkronizasyonu.
- 🇹🇷 **Türkiye Saati (TRT / Europe/Istanbul):** UTC+3 saat dilimi ile gerçek zamanlı gösterge.
- 🌴 / 🏫 **Otomatik Durum Belirleme:** Okullar açık mı, yaz tatilinde mi, ara tatilde mi veya sömestrda mı otomatik algılar.
- 📅 **Merkezi Takvim Sistemi:** 2024-2025, 2025-2026, 2026-2027, 2027-2028 eğitim yılları desteği.
- 📊 **Eğitim İstatistikleri:** Yıl tamamlama oranı (% progress bar), geçen gün, kalan gün ve iş günleri.
- 🌙 / ☀️ **Karanlık & Aydınlık Tema:** Glassmorphism modern UI tasarımı.
- 📅 **Takvime Ekle:** Google Calendar ve Apple/Outlook (.ics) dışa aktarma.
- 🔒 **Güvenlik Koruması:** F12 ve geliştirici kısayolları kısıtlaması.
